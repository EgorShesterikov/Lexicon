Приложение для записи, группировки и заучивания английских слов. Это один HTML-файл — открывается прямо в браузере, без установки, сервера и интернета (кроме автоподстановки данных о слове).

## Быстрый запуск

Ничего скачивать не нужно — нажмите на баннер выше или кнопку **▶ Запустить приложение**, чтобы открыть его прямо в браузере.

- **Сразу, без настройки** — ссылка открывает файл через [htmlpreview](https://htmlpreview.github.io). Удобно, чтобы быстро посмотреть.
- **Офлайн** — скачайте `Lexicon.html` и откройте двойным кликом; всё работает без интернета, кроме автоподстановки.

## Возможности

- **Словарь.** Слова автоматически группируются по частям речи, есть сортировка **«сначала новые»**. Для каждого слова — перевод(ы), транскрипция (IPA), произношение, часть речи и статистика точности. Умный поиск: одна буква показывает все слова на эту букву, два и более символов — поиск по вхождению (в слове или переводе).
- **Добавление слов.** По одному (с автоподстановкой перевода, транскрипции и озвучки) или массово — списком, с окном проверки и правки перед сохранением и возможностью сразу собрать добавленные слова в новую группу. Подтягиваются все варианты значений по частям речи. Повторное добавление уже существующего слова **дополняет** его перевод, а не создаёт дубликат.
- **Группы.** Свои наборы слов (например, по урокам). Списки по умолчанию свёрнуты и раскрываются по клику; при большом числе групп появляется поиск по названию. Быстрое окно **«Добавить слова»** помогает собрать группу галочками с живым поиском и фильтром по части речи.
- **Игра «Карточки» — три режима.** На карточках показывается часть речи, есть озвучка, а длинные слова и переводы автоматически уменьшаются, чтобы поместиться.
  - *Повторение* — переворачивайте карточку сколько угодно, одна кнопка «Следующее слово», без статистики.
  - *Зачёт* — вписываете ответ (перевод или слово по-английски, в зависимости от стороны); переворот карточки засчитывается ошибкой, затем карточка переворачивается и показывает результат. Опциональный таймер по группам сохраняет **лучшее время — только за прогон без ошибок**.
  - *Случайные* — новые случайные английские слова из онлайн-базы с оценкой «знал / не знал»; каждое показанное слово автоматически добавляется в словарь.
- **Статистика.** По каждому слову — точность и число повторений; отдельные режимы «трудные слова» и «ещё не учил»; уникальное лучшее время для каждой группы.
- **Интерфейс.** Аккуратные вкладки-кнопки, интерфейс на английском или русском (переключается в шапке, выбор запоминается) и собственные диалоги подтверждения вместо браузерных. Полное управление с клавиатуры, поддержка скринридеров и режим уменьшенного движения.
- **Резервная копия.** Экспорт и импорт словаря в CSV, сброс всех данных — в меню настроек (⚙️).

## Запуск локально

Открой `Lexicon.html` двойным кликом в любом современном браузере (Chrome, Edge, Firefox). Для удобства можно создать ярлык с иконкой из папки `Icons`.

## Язык

Язык интерфейса переключается тумблером **EN / RU** в шапке. По умолчанию английский; выбор сохраняется в браузере. Направление обучения остаётся английский → русский независимо от языка интерфейса.

## Хранение данных

Словарь и группы сохраняются в `localStorage` браузера (ключ `vocab_app_v1`) и переживают перезапуск. Данные привязаны к браузеру на конкретном компьютере — для переноса используй экспорт/импорт CSV.

## Технологии

Чистый HTML, CSS и JavaScript без сборки и внешних библиотек. Автоподстановка данных использует бесплатные сервисы без ключа:

- [Free Dictionary API](https://dictionaryapi.dev) — транскрипция, произношение, часть речи;
- [MyMemory](https://mymemory.translated.net) и публичный эндпоинт Google Translate — перевод и варианты значений по частям речи;
- публичный API случайных слов с запасным [Datamuse](https://www.datamuse.com/api/) — слова для режима «Случайные».

## Ограничения

- Автоподстановка и режим «Случайные» требуют интернета; при недоступности сервисов поля заполняются вручную.
- Произношение при отсутствии готового аудио синтезируется голосом браузера (Web Speech API).
